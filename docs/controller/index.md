## About vNAAATS

vNAAATS is the toolset used by Gander and Shanwick oceanic controllers. It shows every oceanic flight as a strip on a web-based Flight Data Display, links to EuroScope through a plugin, and includes CPDLC and natTrak alerts. All controllers see the same flight data within seconds. See [vNAAATS](/controller/clients/vnaaats/) to get access and install it.
